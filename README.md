# 静观 · 每日塔罗

[打开网页](https://burning-frappuccino.github.io/still-oracle/)

原创深青古金风塔罗反思工具，直接在浏览器运行，无需登录、API Key 或付费接口。

## 功能

- 完整 78 张牌、原创矢量牌面、正逆位、每日固定三张。
- 三张牌阵：当下状态 / 潜在盲点 / 行动方向。
- 三牌整体解读：把当前模式、潜在张力和优先行动串联起来；保留卡名、位置与正逆位依据。
- 每张牌仍可独立查看具体牌义、风险、小行动与反思问题；不回避困难牌，也不把逆位简单判为坏运。
- 加密随机数、无放回抽牌，不根据提问挑选“好牌”。
- 手记自动保存、晚间复盘、历史补记和 JSON 备份导入导出。
- 手机适配、键盘操作、减少动态效果支持。

## 关于解读

解读由原创牌义和可审查的组合规则生成，不是联网 AI、读心或未来事实预测。塔罗可以作为反思视角，但不保证应验；请同时记录与现实符合及不符合的内容，不据牌面替代证据或作重大决定。

## 隐私与换站点

所有问题、抽牌和手记只保存在每位访问者自己的浏览器中，不上传 GitHub、不写入仓库、无云同步。

旧的私有网址、本地文件版与此 GitHub Pages 网址是不同的存储来源。迁移记录时，请先在旧页面的「我的手记」中导出，再在新网页导入；不能自动读取旧站点的数据。旧版备份继续兼容，整体解读会从原三张牌自动生成，不会重抽。

## 本地运行

- 双击 `打开每日塔罗.cmd`，或直接用现代浏览器打开 `dist/index.html`。
- HTTP 预览：`node server.cjs`，然后打开终端显示的本地网址。
- 功能验证：`node test.cjs`。测试验证代码功能，不证明占卜准确率。

## 部署

GitHub Pages 使用 `.github/workflows/pages.yml`，推送到 `codex/pages` 后先运行功能测试，再只发布 `dist/` 静态目录。网站不需要账号，源码仓库公开；访问者的私人记录不属于公开源码。

工作流基于 [GitHub 官方静态站模板](https://github.com/actions/starter-workflows/blob/main/pages/static.yml)。未来修改时请观察仓库 Actions 的真实部署结果，不把推送成功当作网页更新成功。
